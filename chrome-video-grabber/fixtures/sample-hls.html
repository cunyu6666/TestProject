Public HLS (.m3u8) fixture

Uses Mux’s public Big Buck Bunny test stream (clear, unencrypted VOD). Serve this folder over http://127.0.0.1 (not only file://), load the unpacked extension, open this page, then use the popup’s 合并下载 on the detected m3u8 row.

Master playlist:
https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8

Smaller media playlist (faster merge test, ~240p):
https://test-streams.mux.dev/x36xhzz/url_2/193039199_mp4_h264_aac_ld_7.m3u8

How to test

  1. cd chrome-video-grabber/fixtures && python3 -m http.server 8765 --bind 127.0.0.1
  2. Chrome → chrome://extensions → Load unpacked → chrome-video-grabber/
  3. Open http://127.0.0.1:8765/sample-hls.html
  4. Open Video Grabber popup → expect an HLS / m3u8 row
  5. Click 合并下载 → Chrome Downloads should get a .ts file

Master playlists also work: the extension picks the highest-bandwidth variant. Prefer the smaller media URL above for a quicker smoke test.
